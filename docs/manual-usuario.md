# Manual breve de usuario (borrador)

> Este manual se completará al terminar el prototipo. Es un producto del objetivo específico 2.

## Cómo entrar

Abre el enlace del prototipo en Chrome, Firefox o Edge de escritorio. No necesitas instalar nada ni crear una cuenta.

## Cómo se juega

- Muévete por el campus con las flechas o W A S D y mira alrededor arrastrando el ratón.
- Entra a un aula para empezar un reto. El robot te explica la teoría antes de comenzar.
- Escribe en el editor y pulsa «Ejecutar». La cartelera de la pantalla muestra el resultado.
- Si algo falla, el mensaje te dice qué ocurrió y dónde revisar. Puedes intentarlo las veces que quieras.

## Tu avance

Tu progreso se guarda en este navegador. Para seguir en otro computador, usa el código de continuación que te da el juego.
